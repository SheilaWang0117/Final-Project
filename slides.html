The problem

  • Plans in slides, budgets in spreadsheets, bank exports in HKD, CNY, USD
  • A simple runway ignores the studies about to start
  • Competitor news and guidance arrive without dates, status or applicability
  • Small vet-oncology teams can't justify enterprise CI and FP&A tools

The solution

  • Deterministic cash, burn, runway and milestone funding test
  • Reviewable CSV/XLSX import
  • Cited, dated evidence mapped to milestones
  • Veterinary-aware regulatory scope (FDA CVM vs USDA CVB; MARA not NMPA)

Phase map: pipelines × 12 development phases; gates = value-inflection decisions (paw = passed · amber = next · outline = ahead)

Costs (measured)

  • Per run, live gpt-6-luna: $0.0006 classification · $0.0009 competitor refresh · $0.0025 regulatory · $0.0011 assistant
  • Whole live demo journey: ≈ $0.008
  • Estimates: $0.6/mo for 1 user · $29/mo for 100 users · $2.9K/mo for 10K users (model only; hosting and search extra)
  • 3 cache layers measured: app retrieval, Portkey replay (discovered, now tracked), provider prompt cache

Price from third-party sources ($0.10/$0.01/$0.50 per 1M); not verified against course billing

Safety

  • Agents have no write tools; business tools are read-only; fetching is limited to retrieved candidates
  • Quarantine for instruction-like text · SSRF-safe retrieval · confidential query guard · secret filter · limits
  • Live injection test, 5 variants: 0 secrets leaked, 0 records changed; simulated compromised model blocked
  • Local prototype: accounts and roles needed before sharing

Impact and next steps

  • Measured: classification 0.95 field accuracy · regulatory precision 1.0 / recall 0.8 · all finance tests pass
  • Ocra scientists already use it; this round of changes came from their feedback (navigation, Chinese version, simpler budget and competitor views)
  • Time savings not yet timed: protocol ready to run with them
  • Next: accounts and roles · deeper Asian regulator parsing · licensed data sources · timed user testing
